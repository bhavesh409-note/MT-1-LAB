# CSE5 HTML Project

This repository contains a small HTML practice project developed for CSE5 web design work.

## Files

- `webd1.html` - first HTML page
- `WebD2.html` - second HTML page
- `webD3.html` - third HTML page

## Purpose

The project is intended for learning and practicing:

- HTML structure
- Page layout
- Text and media formatting
- Basic web design concepts

## How to view

Open any of the HTML files in a browser to view the pages.

This project is published on GitHub for learning and portfolio purposes.
